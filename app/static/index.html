NLP Engineering Architecture Blueprint

Context-Aware Toxicity Classifier for Indian & Telugu Code-Mixed Data

1. Two-Stage Production Inference Cascade

Stage 1 Fast Filter (≤ 3ms): Isolated comment evaluated via high-confidence lexical regex + slur canonicalizer. Explicit slurs (>0.90) and obvious benign greetings (<0.15) exit immediately, bypassing GPU overhead for ~75% of traffic.

Stage 2 IndicBERT Cross-Encoder (~17ms): Ambiguous traffic (0.15 to 0.90) is routed to IndicBERT-v3, incorporating preceding parent turns from thread cache via Target-Span Pooling.

2. Target-Span Pooling Head (CLS ⊕ TargetMean)

Standard [CLS] pooling suffers from parent toxicity bleed when a benign reply follows an aggressive parent. Target-Span Pooling solves this by concatenating the global [CLS] representation with the mean-pooled vector of strictly the target tokens:

h_rep = [ h_CLS ; (1 / |Target|) Σ_{i ∈ Target} h_i ] → Linear(2H, H) → GELU → Linear(H, K)

3. Class-Weighted Focal Loss

Extreme toxicity class imbalance is addressed using Focal Loss (α=0.75, γ=2.0):

FL(p_t) = -α_t · (1 - p_t)^γ · log(p_t)

Zeroes out gradients on easy non-toxic examples and concentrates 90%+ updates on hard context-dependent edge cases.

4. 4-Stage Transfer Curriculum

  • Stage 1: Context Mechanics on English Threads (toxic-chat + jigsaw-bias)
  • Stage 2: Telugu MLM Domain Adaptation (IndicCorp 250K)
  • Stage 3: Dravidian Code-Mix & Telugu Slang Fine-Tuning (Bottom 50% frozen)
  • Stage 4: Synthetic Contrastive Thread Fusion & De-escalation (Bottom 75% frozen)
